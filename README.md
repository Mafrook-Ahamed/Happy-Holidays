# Happy Holidays

Responsive React + Vite travel website for Happy Holidays, Thiruverambur, Trichy.

Run locally with `npm install` and `npm run dev`. Build with `npm run build`.

## Features
- Full-screen video hero with a distinct travel clip
- Clickable destination images with descriptions and Book Now enquiry action
- Package catalogue and all published package categories
- Flight search opens Google Flights with selected route, dates, passenger count and cabin
- WhatsApp enquiry form prefilled with travel details
- Responsive mobile navigation and page layouts

Flight search opens provider results externally; it does not issue tickets or confirm bookings. WhatsApp form submissions are enquiries only.
