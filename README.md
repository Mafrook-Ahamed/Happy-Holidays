# Happy Holidays

Responsive React + Vite travel website for Happy Holidays, Thiruverambur, Trichy. Includes cinematic video hero, clickable destination cards, package catalogue, flight search (Google Flights deep link), WhatsApp enquiry form, and mobile layout.

Run with `npm install` then `npm run dev`. Build with `npm run build`.

Flight search displays live provider results externally and does not itself ticket or confirm bookings. WhatsApp form submits an enquiry to +91 75300 50392.
